# configs

## Purpose

- Ultralytics dataset YAMLs for the baseline splits (BDD source, ACDC official, ACDC 5-fold CV) and for each offline synthesis stage (`bdd_s2`, `bdd_s3`, ...).

## Ownership

- Owned by the project root `AGENTS.md`.

## Local Contracts

- Baseline YAMLs are generated by `src/data/write_configs.py`; stage YAMLs are generated by their synth builders (`src/synth/build_dataset.py`, `src/synth/build_s3.py` via `stage_common.write_dataset_config`). Do not hand-edit either.
- `nc: 6` and class names must match `scripts/class_map.py`.
- `train`/`val` must reference manifests under `splits/`, never directories of raw images.

## Work Guidance

- Regenerate after changing splits: `python src/data/write_configs.py`.

## Verification

- `python src/data/write_configs.py` regenerates the YAMLs without error, and each references manifests under `splits/` with `nc: 6`.

- None.
