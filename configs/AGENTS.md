# configs

## Purpose

- Ultralytics dataset YAMLs for the baseline splits (BDD source, ACDC official, ACDC 5-fold CV).

## Ownership

- Owned by the project root `AGENTS.md`.

## Local Contracts

- Generated by `src/data/write_configs.py`; do not hand-edit.
- `nc: 6` and class names must match `scripts/class_map.py`.
- `train`/`val` must reference manifests under `splits/`, never directories of raw images.

## Work Guidance

- Regenerate after changing splits: `python src/data/write_configs.py`.

## Verification

- `python src/data/write_configs.py` regenerates the YAMLs without error, and each references manifests under `splits/` with `nc: 6`.
